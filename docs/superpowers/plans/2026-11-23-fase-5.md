# Fase 5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrar infraestructura endurecida y gates verificables de IaC/contenedor.

**Architecture:** Dockerfile multi-etapa y Compose local. El build produce una imagen que el job IaC descarga y escanea, sin reconstruirla.

**Tech Stack:** Node.js 24, Docker Compose, Checkov 3.4.7, Trivy 0.76.2, GitHub Actions.

**Spec:** docs/superpowers/specs/2026-11-23-fase-5-design.md, aprobado en este chat.

## Global Constraints

- Conservar UID 65532 y vulnerabilidades de negocio del laboratorio.
- Exponer únicamente 127.0.0.1:3000. Sin secretos reales, nube ni publicación remota.
- Fijar bases por digest; Checkov bloquea sus checks aplicables fallidos; Trivy bloquea CRITICAL con parche.
- Sin `continue-on-error` ni `|| true` en gates. Publicar reportes incluso ante fallo.
- Reutilizar checkout en rama `codex/fase-5-infra`. Preservar cambios ajenos.

## Review Focus

- Salud de distroless: invocar Node por ruta absoluta, sin shell.
- Fallo de escáner o reporte vacío: fallo visible, nunca aprobado por ausencia de resultados.
- Vulnerabilidades heredadas: mantener reportes completos y no crear excepciones para pasar.
- Compose: validar restricciones y reconocer cobertura real de los escáneres.
- Imagen escaneada: mismo tag SHA y artefacto que produce build.
